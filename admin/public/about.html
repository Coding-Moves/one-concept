The review workspace

Good learning starts with a human review.

One Concept is a daily learning app by Coding Moves. Its private review workspace lets invited editors check lessons, request corrections, and approve complete learning content before it reaches learners.

How the workspace works

An owner assigns lessons to invited reviewers. Reviewers inspect the explanation, example, learning objective, flashcard, and questions; they can leave comments or request changes. Only authorized people can approve or publish content. The workspace requires an individual account and an authenticator code.

The owner can authorize a send-only Gmail connection to email reviewers about assigned work and deadlines. This connection does not read the owner's mailbox. Review links still require normal sign-in and authentication.
